## 三、密码算法完整规格

### 3.1 双组件架构（第 216-217 轮修正）

此前"纯 ARX 无标准算法"结论修正为：**keystream 是 ARX 流密码，tag 是 SHA-256 MAC**。

证据：
- SHA-256 IV（`0x6a09e667`...`0x5be0cd19`）由 `0x18042b970` 写入 112B 上下文（heap
  `0x200001000a0`，state @ +0x50），inst 4149897，逐字匹配 FIPS 180-4。
- 全部 64 个 SHA-256 轮常量 K（`0x428a2f98`...`0xc67178f2`）在 DLL 中 64/64 存在（LE）。
- ~90 种 HMAC-SHA256/SHA-256 tag 构造（`test_mac_systematic.py`）全部 0/10 匹配 →
  tag MAC 密钥是 key-schedule 派生的（非原始会话密钥）。

### 3.2 keystream：ARX 流密码

```
keystream = F(key, nonce)  (确定性)
ciphertext = plaintext XOR keystream
64B 块 = 16 × 32-bit LE word
```

### 3.3 ARX 轮函数（已解码）

```python
def arx_round(s1, s2, const3, constA):
    s1 ^= ((const3 ^ s1) - s2) & 0xFFFFFFFF
    s1 ^= (constA + s1 + s2) & 0xFFFFFFFF
    return s1, s2
# const3 = word[VIP+3], constA = word[VIP+0xa]
```

### 3.4 VM dispatch（静态证明，里程碑 17）

```python
index = (word[VIP+idx_off] - key + 0x5214a88c) & 0xffff
key_after = key - index_full          # DATA-DRIVEN: key = word[VIP+key_off]
# handler 表 0x180c64ebd（1612 条目）
```

### 3.6 key-schedule ARX 循环结构（数据驱动，第 222 轮确认常量地址）

key-schedule 是**数据驱动 ARX 循环**：字节码字（`word[VIP+K]`）决定操作哪些上下文槽，
ARX 常量嵌入 handler body。22 个常量全部在 `.bugland` 中定位。

**keystream 生成 = 124-handler 稳态循环**（`keystream_history_cfg_summary.txt` 的 common_suffix）：
chain A（`0x18099089e→0x180990a93→0x180990b21`，1300 次）→ chain D（`0x180b41fb8→...→0x180b423a3`）
→ chain B（`0x1809bfebb→0x1809bff47→0x1809c012a`）→ chain C（`0x180a02a99→...→0x180a02ca5`）
→ ... → **fold 入口 `0x180c27652`**（无后继）。这是 key-schedule ARX 循环的完整 handler 序列，
fold 在循环末端。

| 链 | 常量 | 地址 |
|----|------|------|
| B | `0x5f5c808f`/`0x3b6a3d7a`/`0x4eceee25` | `0x1809bff27`/`0x1809bff43`/`0x1809bff79` |
| C | `0x558a625a`/`0x681b64d8`/`0x6abd113b` | `0x180a02ba1`/`0x180a02bc2`/`0x180a02ca1` |

handler 语义（chain B 示例，`0x1809bfebb`）：读 `word[VIP+0x10]` 作上下文偏移 → 加载

槽位索引 + 常量混合构成 ARX 循环。

### 7.1 nonce 是 keystream 的确定性输入（第 220 轮确认）

`test_nonce_dependence.py` 用 vm_context2 的 10 组（同 key、10 nonce、10 keystream）证明：
10 个 keystream 全部不同，且**零 shift 关系**（非计数器/非 nonce 无关）。故：

```
keystream = ARX_cipher(key, nonce)   # nonce 是真实输入，非仅信封字段
```

且 nonce 由 VM 内部定制 CSPRNG 生成（无 BCryptGenRandom/RtlGenRandom/CryptGenRandom 调用，
`test_nonce_sha256.py` 排除 SHA-256 派生）。MAC 派生密钥也非 keystream 派生
（`test_mac_keystream_key.py` 12 种构造 0/10 匹配），是 key-schedule 内部派生的。

### 7.2 nonce 非线性混合（第 230 轮确认）

`test_nonce_linearity.py`：word0 差分 `word0_i ^ word0_j` 与 nonce 差分 `nonce_i ^ nonce_j`
无任何线性/单字关系（0/45 匹配）。**nonce 经 ARX key-schedule 非线性混入 keystream**，
排除任何简单/线性捷径，确认是真正的非线性 ARX 密码。
