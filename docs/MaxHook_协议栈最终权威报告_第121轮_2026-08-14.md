## 2. 重大方向性突破（第 118-120 轮）

**此前 17 轮误判为"数据缺口"**（缺 key/活态 heap）。第 118 轮重读 milestone 17 发现：

- **dispatch 公式已静态证明**：`index = (word[VIP+idx_off] - key + 0x5214a88c) & 0xffff`
- **rolling key 数据驱动**：`key = word[VIP+key_off]`，`key_after = key_before - index_full`
  （非此前假设的 `key ^= key+0x4111` 递推）
- **VIP 前进**：`VIP += i32[VIP+adv_off]`
- **handler 表已解密**（177/177 target 命中）

**结论**：key-schedule 字节码可**完全离线静态解码**，无需真机/活态 heap/key 字节。
