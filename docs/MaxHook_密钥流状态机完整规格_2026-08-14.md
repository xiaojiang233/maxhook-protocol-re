# MaxHook 密钥流密码状态机 — 完整规格（第 103 轮汇总）

日期：2026-08-14
范围：纯离线。来源：keystream_history（52 快照）+ fold 规格 + key-schedule ARX 循环提取 + DLL 全段扫描。

## 一、密码类型（决定性结论）

**bytecode-compiled ARX 流密码**（无静态 S-box）。证据：

1. **无静态 S-box**（`scan_sbox_dll.py`）：runtime-unpacked DLL 全部可写段（24MB）扫描，
   0 个 256 字节置换表，0 个 ≥200 不同值/256B 的高熵窗口。故 S-box（若有）是运行时 key 派生的，
   或密码是纯 ARX 无 S-box。
2. **key 全扩散**（`test_key_dependence.py`）：相同 (block, byteoff) 位置，3 个 key 下 keystream
   字节 9/9 全不同（0 匹配）。
3. **nonce 非弱加性**（`analyze_boundary2_session.py`）：KS1^KS2 ≠ N1^N2。

## 二、完整状态机（跨 52 快照实测，全部槽位语义）

VM context 基址 `0x18098c884`（768B）。状态槽：

| 槽 | 语义 | 实测（3 调用一致） |
|----|------|-------------------|
| `+0x1e` | key-schedule 轮状态字（round update 目标） | XOR 时刻为 0（已消费/清零） |
| `+0x26` | 块计数器 | 0,1,2,... 每 64B 块 +1 |
| `+0x36` | 位置计数器 | 每块前进 |
| `+0x45` | 状态缓冲偏移指针 | 每块 +0x20 |
| `+0x61` | 指针表（模块 .data `0x180835f10`） | 非 S-box（指向代码指针表） |
| `+0x6d` | VIP（字节码指令指针） | 每块前进 |
| `+0xa` | 计数器 | 0xfe 恒定（3 调用） |
| `+0xb5` | **密钥流字节输出** | = keystream_byte |
| `+0xbd` | key 缓冲指针（heap） | `0x13a4e192070`（pid 42948） |
| `+0xd9` | 块内字节偏移 | 0x00/0x40/0x80/0xc0 循环 |
| `+0xe5` | 状态累加字 | 0x34 恒定（3 调用） |
| `+0xed` | 状态字 | 0x2c 恒定（3 调用） |
| `+0x106` | 状态值 | 0xe9 恒定（3 调用） |
| `+0x143` | 状态字（低字节=字节偏移计数器 0x00/0x40/0x80/0xc0；高字节=堆指针/哨兵） | call1/3=`0xfb760c32465f...`，call2=`0xffff...`（哨兵 -1） |
| `+0x14a` | 位置计数器 | 每块前进 |
| `+0x235` | 密钥流字节双缓冲 B（= `0x1807483e0` 模块指针） | 与 +0xb5 交替 |

**关键发现（经 verify_state_constancy.py 校正）**：
- `+0x143` 的高字节是**堆指针**（call1/3=`0xfb760c32465f`，call2=哨兵 `0xffff`），**非固定常量**；
  低字节是字节偏移计数器（0x00/0x40/0x80/0xc0 循环）。
- **真正的跨 key 固定值**是模块指针槽（DLL 固定加载于 `0x180000000`）：`+0x6d=0x180b1648d`、
  `+0x85=0x180c64ebd`（handler 表）、`+0x235=0x1807483e0`，以及 `+0x1e=0`（始终零）。
- **跨 key 变化的堆指针**（ASLR）：`+0x45`/`+0xbd`（key 缓冲 `0x13a4e194e70`/`0x139fd2678e0`/
  `0x1399a4e9c7b`）、`+0x61`。

## 三、key-schedule 轮函数（第 10 轮已解码 + 第 99 轮 ARX 循环）

轮函数（fold 区域 `0x180c27d03..0x180c27f97`）：

```text
state[0x1e] ^= (word[VIP+3] ^ state[0x1e]) - state[0x143]      ; round A
state[0x1e] ^= word[VIP+0xa] + state[0x1e] + state[0x143]       ; round B
```

轮常量（`word[VIP+3]`、`word[VIP+0xa]`）**嵌入 VM 字节码流**（`.bugland`，离线可读）。

ARX 循环（第 99 轮，4 主链 + 4 辅助链）轮常量：`0x5f5c808f`/`0x558a625a`/`0x6abd113b`/
`0x7f594fcf`/`0x616c560b`/`0x472793ed`/`0x4bfba08f`/`0x453d7de7`/`0x3e0cc8b0`/`0x3b86d410`/
`0x6220b8ca`/`0x662ff97c`/`0x3c02264d`/`0x31d126f2`/`0x5e800fc4` 等（14/16 已内存写交叉验证）。

## 五、复现路径与唯一缺口

密码 = 纯 ARX（无静态 S-box），轮函数 + 常量全部离线可读（字节码在 `.bugland`，常量已全识别）。
复现只需：**key + nonce → 初始状态**（key-schedule 展开）→ 执行字节码轮函数 → fold → store32。

唯一缺口 = **key-schedule 的初始状态展开**（key+nonce 如何初始化为 state[0x1e]/[0x143] 等槽）。
这需要执行 VM 字节码的 key-schedule 前缀（第 25-57 轮工程），或一个"加密进行中"的 heap dump
（key 字节 `0x13a4e192070` + 状态缓冲）。本地 dump（pid 41264）是空闲态，key-schedule 状态已清除。
