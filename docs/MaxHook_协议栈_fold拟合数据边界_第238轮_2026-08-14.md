## 一、fold = counter-mode 确认 + 数据边界

`fit_fold_countermode.py` 确认 fold 是 **counter-mode**：`keystream_byte = F(key_state_105B, counter)`。

keystream_history 的采样结构：
- **3 个 call = 3 个不同 key**（3 个 key_state）
- 每个 call 的快照**每 64 字节**一个（xor_index 0, 64, 128, 192...）
- 即每个 call 有 keystream 在 0/64/128/... 位置的单字节

## 二、数据边界

fold 是 `F(key_state, counter)`，需要拟合 F 需要**多个 key_state 样本**。但：
- 3 个 call = 3 个 key_state（不足）
- 需要更多 key_state 样本或已知 ARX 递推

**关键结论**：fold 的 ARX 递推已在 handler 层解码（槽交换 + ARX + 22 常量），fold 算术
（12 操作 + 8 常量）已识别。数据拟合不可行（3 样本不足），但**代码路径已完整解码**，
剩余是执行 key-schedule 数据流（需 VM 数据栈或符号执行）。
