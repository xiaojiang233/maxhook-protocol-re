## 1. 协议信封与加密函数（已 100% 恢复）

```text
{ sv:3, kid, nonce, ciphertext, tag }
输出对象 = 4 连续 MSVC std::string：
  +0x00 kid (16B 大写 hex)  +0x20 nonce (12B 小写 hex)
  +0x40 ciphertext (hex)    +0x60 tag (16B 小写 hex)

加密函数 0x180324610：
  RCX=output  RDX=input32(16B AAD "v3|hpac.v3.session.report.req")
  R8=input64(32B key hex)  R9=context  [RSP+0x28]=plaintext
nonce 是输出（内部 CSPRNG），非 key 哈希。
```

## 2. 流密码类型（决定性结论，第 103 轮证明）

**定制 word 型（32-bit）ARX 流密码，无静态 S-box**：

- `scan_sbox_dll.py`：DLL 全部可写段（24MB）扫描，**0 个 256 字节置换表、0 个高熵窗口** →
  无静态 S-box。
- `test_key_dependence.py`：相同 (block, byteoff) 位置，3 key 下 keystream 字节 **9/9 全不同** →
  key 全扩散（从第 0 字节起）。
- `analyze_boundary2_session.py`：KS1^KS2 ≠ N1^N2 → nonce 非弱加性混合。
- 已证伪 1508 项标准原语（AES/ChaCha/Salsa/BLAKE/HMAC/RC4/SM4/RC5/6 等 0 命中）。

```text
keystream = F(key, nonce)    ciphertext = plaintext XOR keystream
64B 块 = 16×32-bit LE word，流式连续、块间无重复。
```

## 3. 生成链（已 100% 恢复）

```text
key(32B)+nonce(12B)
  → key-schedule（VM 字节码，轮函数已解码）
      state[0x1e] ^= (word[VIP+3] ^ state[0x1e]) - state[0x143]
      state[0x1e] ^= word[VIP+0xa] + state[0x1e] + state[0x143]
  → context 768B 状态（槽位语义全解，见 §4）
  → 字生产者 0x180b8c7aa（6 槽 {0xb5,0x26,0xd9,0x61,0xbd,0x106}）

  → store32 0x18041a860（EDX=密钥流字）
  → 0x1809c5561 xor byte [r8], r12b
  → ciphertext
```
